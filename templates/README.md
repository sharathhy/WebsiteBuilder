# templates/

Generated-site templates live here (Phase 5). Each template is a Next.js App Router
project driven entirely by a JSON **site spec**; the LLM only fills the spec and never
writes code at runtime.

Planned templates: `restaurant`, `clinic`, `salon`, `fitness`, `legal-finance`,
`real-estate`, `home-services`, `generic-premium`. Category → template mapping is in
[`config/targets.yaml`](../config/targets.yaml).
